# 篮球小子 · 阅读冒险

为中学低年级学生阅读《篮球小子》准备的互动游戏。学生通过人物互动、阅读挑战和投篮训练，翻书寻找答案、积累经验值，并逐步成为篮球队正式球员。

支持电脑、平板和手机；投篮游戏建议横屏操作。体感模式需要允许使用摄像头，并保持网络连接。

## 开始游戏

打开游戏网页，输入名字和班级即可开始。游戏包含玩法教学，并通过已配置的云端服务保存进度和显示排行榜。

## 发布

将解压后的 `index.html`、`assets`、`shoot-assets`、`growth-assets`、`audio`、`vendor` 文件夹、`.nojekyll` 和本文件放在 GitHub 仓库根目录，然后启用 GitHub Pages。请保留所有文件夹内的全部文件及原有文件名。

## 音乐与音效

- 背景音乐由 SUNO 生成，仅在本游戏中用于教育活动。
- 音效来自 Pixabay 音效资源，仅在本游戏中用于教育活动，并遵循各素材的适用许可。
